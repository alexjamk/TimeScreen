# TimeScreen Control — Родительский контроль для Windows

Программа для ограничения времени использования компьютера. Архитектура: служба Windows (SYSTEM) + GUI-приложение. Экран блокировки и таймер работают без повышения прав; изменение общих настроек требует UAC и пароль TimeScreen.

## Возможности

- ✅ **Графический интерфейс** — вкладки «Общие», «Пользователи», «Интервалы», «Перерывы», «Таймер»
- ✅ **Служба Windows** — мониторинг под SYSTEM, проверка каждые 5 секунд и автоматический перезапуск блокировщика
- ✅ **Гибкое расписание** — интервалы с настройкой дней недели, включая overnight (22:00–08:00)
- ✅ **Регулярные перерывы** — блокировка на N минут после M минут фактической работы с предупреждениями за 10, 5 и 1 минуту
- ✅ **Блокировка всех мониторов** — `EnumDisplayMonitors`, каждый экран получает полноэкранное окно
- ✅ **Перетаскиваемый таймер** — обратный отсчёт до блокировки/разблокировки, позиция сохраняется
- ✅ **Авторазблокировка** — экран сам закроется, когда настанет разрешённое время
- ✅ **Grace-период** — 10 минут без повторной блокировки после ввода пароля
- ✅ **Разблокировка по паролю** — bcrypt-хэширование (12 раундов) с солью
- ✅ **Admin Unlock** — вход как администратор Windows сбрасывает блокировку
- ✅ **Multi-user** — блокировка только активной сессии выбранного пользователя; администратор остаётся доступен
- ✅ **Защита конфигурации** — ACL + HMAC-SHA256, при повреждении включается fail-closed режим
- ✅ **Кнопки выключения** — завершение работы, перезагрузка, сон прямо с экрана блокировки
- ✅ **Автономная работа** — собранный EXE не требует Python или интернета

### Два исполняемых файла

| Файл | Формат | Назначение |
|------|--------|------------|
| `TimeScreenControl.exe` | `--onefile --windowed` | GUI: настройки, таймер, экран блокировки |
| `TimeScreenService.exe` | `--onedir --console` | Служба Windows под SYSTEM |

**Почему `--onedir` для службы:** PyInstaller `--onefile` bootloader перезапускает сам себя (меняет PID) для ASLR на Windows 10/11. SCM отвергает подключение с другого PID → Error 1053. `--onedir` не перезапускается, PID сохраняется.

## Быстрый старт

### Сборка из исходников (компьютер разработчика)

Для сборки установщика нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php). Его можно установить командой:

```powershell
winget install --id JRSoftware.InnoSetup --exact
```

```bash
cd TimeScreenControl
build.bat
```

Скрипт автоматически:
1. Проверит/установит PyInstaller
2. Соберёт `TimeScreenControl.exe` (onefile, windowed)
3. Соберёт `TimeScreenService\` (onedir)
4. Упакует всё в `dist\Release\`
5. Создаст графический установщик `dist\Installer\TimeScreenControl-Setup-3.1.exe`

### Установка (целевой компьютер)

1. [Скачайте установщик TimeScreen Control 3.1](https://github.com/alexjamk/TimeScreen/releases/download/3.1/TimeScreenControl-Setup-3.1.exe)
2. Запустите установщик и подтвердите UAC
3. Мастер скопирует файлы, установит и проверит службу
4. На последней странице оставьте флажок запуска, чтобы сразу открыть настройки

Установщик создаёт ярлык в меню «Пуск» и опциональный ярлык на рабочем столе. Ручные `install.bat`/`uninstall.bat` сохранены только для диагностики и разработки.

### Первый запуск

1. Откройте «TimeScreen Control» из меню «Пуск»
2. Программа предложит задать пароль администратора (минимум 4 символа)
3. Вкладка **Общие** — вкл/выкл защиты, смена пароля
4. Вкладка **Пользователи** — выбор контролируемых пользователей. Пустой список никого не блокирует
5. Вкладка **Интервалы** — настройка разрешённого времени по дням недели
6. Вкладка **Перерывы** — опциональный цикл «перерыв N минут каждые M минут работы»
7. Вкладка **Таймер** — отображение обратного отсчёта

### Полное удаление

Используйте «Параметры Windows → Приложения → TimeScreen Control → Удалить». Деинсталлятор остановит и удалит службу, программу и все настройки из `%PROGRAMDATA%\TimeScreen`. Следующая установка начнётся с настройки нового пароля и интервалов.

```
┌──────────────────────────────────────────────────┐
│  СЛУЖБА (TimeScreenService.exe, SYSTEM)           │
│  Session 0, работает от LocalSystem                │
│                                                    │
│  Каждые 5 сек:                                    │
│  1. Читает pc_config.json                         │
│  2. Проверяет, включена ли защита                  │
│  3. Проверяет, контролируется ли текущий           │
│     пользователь                                  │
│  4. Проверяет время                               │
│  5. Если запрещено → запускает LockScreen         │
│     в сессии пользователя через                   │
│     CreateProcessAsUser                           │
│  6. Если разрешено → убивает LockScreen            │

               │
               ▼
┌──────────────────────────────────────────────────┐
│  LockScreen (TimeScreenControl.exe --locker-mode) │
│  Сессия пользователя, GUI                         │
│                                                    │
│  - Полноэкранное окно на всех мониторах            │

│  - Зелёный: обратный отсчёт до блокировки          │
│  - Жёлтый: grace-период                           │
│  - Красный: компьютер заблокирован                 │

│  - Правый клик: скрыть/сбросить позицию            │
```

## Безопасность

| Действие | Требуется |
|----------|-----------|
| Изменение расписания | Пароль |
| Вкл/выкл защиты | Пароль |
| Смена пароля | Старый пароль |
| Разблокировка экрана | Пароль |
| Admin Unlock (Windows) | Права админа |
| Установка/удаление службы | UAC |
| Удаление программы | UAC |
| Целостность конфига | ACL + HMAC-SHA256 (повреждение = lockdown) |

**Дополнительные меры защиты:**
- Пароли хэшируются **bcrypt** (12 раундов) — защита от brute-force
- Конфиг в `%PROGRAMDATA%` — запись только от админа
- Установка в `%PROGRAMFILES%` — защита от подмены EXE
- Межпроцессная блокировка и атомарная замена файла — защита от гонок и частичной записи
- Парольная разблокировка проверяется SYSTEM-службой через локальный named pipe
- Нет recovery-режима и backdoor

## Файлы и расположение

После установки:

```
%PROGRAMFILES%\TimeScreenControl\
├── TimeScreenControl.exe              — GUI (оконный)
└── TimeScreenService\                 — Служба (onedir)
    ├── TimeScreenService.exe
    └── _internal\                     — Python runtime + зависимости

%PROGRAMDATA%\TimeScreen\
├── pc_config.json                     — конфиг (пароль, расписание, пользователи)
├── break_state.json                   — прогресс рабочих циклов по пользователям
├── service.pid                        — PID службы
└── service.log                        — журнал работы
```

Позиция таймера и PID агента хранятся отдельно в `%LOCALAPPDATA%\TimeScreen` каждого пользователя.

Ярлык:
- `%PROGRAMDATA%\Microsoft\Windows\Start Menu\Programs\TimeScreen Control\TimeScreen Control.lnk`

## Решение проблем

### Служба не запускается (Error 1053)
- Убедитесь, что `TimeScreenService.exe` собран с `--onedir` (не `--onefile`)
- Проверьте, что `_internal\` лежит рядом с `TimeScreenService.exe`
- Запустите `uninstall.bat` и переустановите службу

### Служба висит в START_PENDING
- Старая служба удалена не полностью → перезагрузите ПК
- Или удалите через реестр: `HKLM\SYSTEM\CurrentControlSet\Services\TimeScreenControl`

### Таймер не показывается
- Защита не запущена → откройте настройки и включите защиту

### Мерцание экрана
- В актуальной версии исправлено: `-alpha` вместо `-transparentcolor`, `CREATE_NO_WINDOW` для subprocess

### Блокируется только один монитор
- Используется `EnumDisplayMonitors` — все мониторы блокируются

### Забыли пароль
- Или используйте Admin Unlock на экране блокировки
- Для полного сброса остановите службу и удалите от администратора всю папку `%PROGRAMDATA%\TimeScreen`, затем переустановите программу. Удаление только `pc_config.json` намеренно включает lockdown.

## Ограничение Windows

LockScreen является обычным окном интерактивной сессии, а не защищённым рабочим столом Windows. Служба восстанавливает закрытый блокировщик, но абсолютную защиту от пользователя с административными правами обеспечить невозможно. Для ребёнка следует использовать отдельную стандартную учётную запись без прав администратора.
