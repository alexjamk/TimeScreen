# TimeScreen Control v3.1

Система родительского контроля для Windows с защитой от обхода.

## 📋 Возможности

- **Временные интервалы** - гибкое расписание использования компьютера
- **Контроль пользователей** - выбор конкретных пользователей или всех
- **Защита паролем** - bcrypt хэширование с солью, проверка разблокировки службой SYSTEM
- **Перетаскиваемый таймер** - показывает оставшееся время до блокировки/разблокировки
- **Экран блокировки** - полноэкранная блокировка с возможностью выключения/перезагрузки
- **Льготный период** - 10 минут на завершение дел после истечения времени
- **Регулярные перерывы** - перерыв N минут после M минут фактической разрешённой работы
- **Целостность конфигурации** - ACL, HMAC-SHA256 и fail-closed загрузка

## 🚀 Установка

1. Запустите `dist/Installer/TimeScreenControl-Setup-3.1.exe`
2. Подтвердите запрос UAC и следуйте указаниям мастера
3. Установщик скопирует файлы, зарегистрирует и проверит службу
4. На последней странице можно сразу запустить настройки

### Требования

- Windows 10/11
- Права администратора для установки службы
- Python и сторонние библиотеки на целевом компьютере не требуются

### Полное удаление

Удаление через «Параметры Windows → Приложения» удаляет службу, файлы программы и все настройки из `%PROGRAMDATA%\TimeScreen`. После повторной установки потребуется заново задать пароль и интервалы.

## ⚙️ Использование

### Первый запуск

При первом запуске программа предложит установить пароль администратора.
**Запомните пароль!** Без него вы не сможете изменить настройки.

### Настройка защиты

1. **Общие** - включение/выключение защиты, управление паролем
2. **Пользователи** - выбор контролируемых пользователей; блокируется только активная сессия выбранной учётной записи
3. **Временные интервалы** - настройка разрешённого времени
4. **Перерывы** - опциональная блокировка на N минут после M минут работы
5. **Таймер** - настройки отображения таймера

### Регулярные перерывы

- Рабочее время считается отдельно для каждой выбранной учётной записи
- Учитывается только активное время внутри разрешённого расписания
- Сон, выключение, другая учётная запись и блокировка не входят в рабочий счётчик
- За 10, 5 и 1 минуту показываются небольшие самозакрывающиеся предупреждения
- После N минут перерыва начинается новый рабочий цикл

### Временные интервалы

- Добавьте интервалы, когда использование **РАЗРЕШЕНО**
- Вне этих интервалов компьютер будет заблокирован
- Поддерживаются overnight интервалы (например, 22:00-08:00)

### Таймер

- Показывает время до следующей блокировки/разблокировки
- Можно перетаскивать мышью в любое место экрана
- Правый клик для контекстного меню (скрыть, сбросить позицию)

## 🔒 Безопасность

- Пароли хэшируются алгоритмом **bcrypt** с солью
- Конфигурация защищена контрольной суммой
- Служба работает от SYSTEM account
- Служба проверяет и восстанавливает блокировщик каждые 5 секунд
- Нет уязвимого recovery режима

## 🛡️ Защита от детей

Программа учитывает пытливость детей:

- Конфигурация в `%PROGRAMDATA%` (требует прав админа)
- Установка в `%PROGRAMFILES%` (требует прав админа)
- Служба перезапускается при попытке остановки
- Экран блокировки нельзя закрыть обычными способами
- Нет ярлыков "Защита" - только настройки

## 📝 Удаление

1. Запустите `install/uninstall.bat` **от имени администратора**
2. Выберите, сохранить ли конфигурацию
