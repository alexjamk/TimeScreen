# TimeScreen Family PWA

Веб-кабинет для удалённого управления TimeScreen Control. Требуется PHP 8.1+ с PDO SQLite и HTTPS.

1. Скопируйте содержимое каталога в корень `https://time.k-alex.ru/`.
2. Создайте `private/config.php` по образцу `private/config.example.php` и сгенерируйте отдельный случайный `app_key` длиной не менее 32 символов.
3. Дайте PHP права записи только в `private/`; веб-серверу запретите отдавать этот каталог.
4. Убедитесь, что веб-сервер разрешает `index.php`, `api.php` и `verify.php` только из этого приложения.
5. Настройте доставку исходящей почты и проверьте подтверждение регистрации.

## Защита рабочего сервера

- Оставьте `private/.htaccess` на месте и после каждой публикации проверяйте, что запросы к `private/config.php` и базе возвращают `403`.
- Отключите показ ошибок PHP пользователю (`display_errors=Off`), включите журналирование и регулярно обновляйте PHP.
- Размещайте домен за CDN/WAF с защитой от DDoS и ограничениями запросов. Встроенные лимиты приложения защищают авторизацию и API от перебора, но не могут остановить объёмную атаку до веб-сервера.
- Если используется reverse proxy, ограничьте прямой доступ к origin-серверу адресами proxy. Приложение намеренно использует только `REMOTE_ADDR` и не доверяет подделываемым заголовкам `X-Forwarded-For`.
- Делайте зашифрованную резервную копию каталога `private`, ограничьте права FTP/панели и меняйте `app_key` только с одновременным завершением всех сессий и повторным связыванием устройств.
- Не публикуйте реальные `config.php`, SQLite, почтовые пароли и ключи деплоя. CI запускает Gitleaks по полной истории каждого изменения.

Устройство работает только через исходящие HTTPS-запросы. Токены устройств хранятся на сервере в виде HMAC, сессии используют `Secure`, `HttpOnly`, `SameSite=Strict`, а изменяющие запросы требуют CSRF-токен. Настройки локального пароля и его хэш не входят в протокол синхронизации.

Файл `private/config.php` и база SQLite исключены из Git. Не публикуйте их и не помещайте базу в доступный из браузера каталог без запрета доступа.
